```text
HelloWorld.java
      │
      ▼

      │
      ▼
HelloWorld.class
   Bytecode
      │
      ▼
     JVM
      │
      ▼
    Output
```

## `javac` vs `java`

One of the first distinctions I learned:

| Command                 | Purpose                   |
| ----------------------- | ------------------------- |
| `javac HelloWorld.java` | Compiles the source code  |
| `java HelloWorld`       | Runs the compiled program |

So:

```text
.java  → Source code
.class → Bytecode
javac  → Compilation
java   → Execution
JVM    → Runs the bytecode
```

## A Small Lesson That Stood Out

If I modify the `.java` source file, I need to compile it again before running the program.

Otherwise, I can end up running the previously generated bytecode.

That was a simple concept, but understanding it made the compilation/execution process much clearer.
