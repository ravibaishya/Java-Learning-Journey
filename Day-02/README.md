# Java Program Execution — Day 2

## What I Learned

Today I understood what happens between writing Java code and getting the output.

A Java program goes through these stages:

.java source code
        ↓
      javac
        ↓
.class bytecode
        ↓
       JVM
        ↓
      Output

## Compilation vs Execution

### Compilation

`javac HelloWorld.java`

The compiler checks the Java source code according to Java's syntax and rules.

If compilation is successful, bytecode is generated as a `.class` file.

### Execution

`java HelloWorld`

The JVM loads the bytecode and starts execution from the `main()` method.

## Important Understanding

`javac` → compiles the source code

`java` → starts execution

`.java` → source file

`.class` → bytecode

`main()` → starting point of a basic Java application

## One Practical Lesson

If I change the source code, I need to compile it again before running the program.

Otherwise, I may still be executing the previously generated bytecode.
