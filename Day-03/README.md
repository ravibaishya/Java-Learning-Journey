# Day 03 — Java Classes, Methods & Program Flow

Day 03 focused on the basic structure of a Java program and how individual pieces fit together.

## Topics Covered

- Classes and meaningful class names
- Class structure and boundaries
- `main()` method
- `public`, `static` and `void`
- Methods
- Method naming
- `String[] args` in `main()`
- PascalCase and camelCase
- `print()` and `println()`
- Multiple classes
- Compilation and execution
- Requirement → Design → Development → Build → Test

## Examples

The `examples` folder contains small programs used to understand individual concepts:

- `AccountInfo`
- `EmployeeInfo`
- `MainMethod`
- `MethodExample`
- `CamelCase`
- `PublicPrivate`
- `PrintVsPrintln`
- `MultipleClasses`

## Exercises

The `exercises` folder contains simple real-world programs based on the same concepts.

The examples use scenarios such as:

- banking
- employees
- customers
- payments
- products
- orders
- travel
- hotels
- hospitals
- offices

The focus is on getting comfortable with Java's basic program structure and writing readable classes and methods.

## Execution Flow

```text
Source Code
    ↓
Compiler
    ↓
Bytecode
    ↓
JVM
    ↓
main()
    ↓
Program Output
```

## Key Takeaway

> Understand the requirement first, then decide the design, write the code, build it and test it.

```bash
javac AccountInfo.java
```
