# Day 03 Practice Guide

Work through the programs in order.

### 1. Read
Look at the class name, `main()` method and print statements.

### 2. Type
Recreate the program yourself instead of only copying it.

### 3. Run
Compile and execute the program.

### 4. Change
Change the displayed details and observe the output.

### 5. Experiment
Try a different heading or output arrangement while keeping the same Java structure.

### 6. Explain
Be able to explain what the class, `main()` method and print statements are doing.

Once the basic programs are comfortable, move to the method-based examples at the end of the exercise list.
